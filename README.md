# m3undle-lab

Deterministic integration-test harness for [M3Undle](https://github.com/Sydney-Elvis/M3Undle),
built on top of [se-lab](https://github.com/Sydney-Elvis/se-lab).

## Status

This repo is a scaffold. The active development harness still lives in the private
`m3undle-lab-private` repo while it's being migrated onto se-lab — see se-lab's
`.ai_docs/roadmap.md` for the migration plan and current phase.

se-lab is included as a git submodule at `se-lab/`. After cloning:

```
git submodule update --init
```
